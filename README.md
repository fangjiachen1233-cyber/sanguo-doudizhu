# 三国画风斗地主 - Demo

这是项目初始骨架（Phaser 3 + TypeScript），用于后续开发一个带三国角色和技能的单机斗地主网页游戏原型。

快速运行：

1. 安装依赖：

```bash
npm install
```

2. 启动开发服务器：

```bash
npm run dev
```

3. 打包：

```bash
npm run build
```

说明：当前为骨架版本，使用占位立绘（SVG）和基础 AI。后续我会把高质量立绘（SDXL prompts 已添加）替换到 assets/portraits 下，构建后资源体积将 >10MB（以满足你的要求）。
